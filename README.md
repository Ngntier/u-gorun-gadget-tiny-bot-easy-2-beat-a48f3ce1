A tiny paper-trading bot for hourly Solana prices: mean-reversion dip buys (RSI + Bollinger) plus momentum breakout buys across 7 assets (FARTCOIN, JITOSOL, POPCAT, RAY, SOL, WETH, WIF), with take-profit, stop-loss and trailing-stop exits. Paper money only, no network, fully deterministic. Dev window: net PnL −167.99 USDC, +701.34 USDC over the buy-and-hold baseline, 16 trades, max drawdown 3.77%.

## Run it

```sh
python3 -P -s main.py
```
